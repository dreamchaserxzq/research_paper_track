# 2026-10-02 研究更新：从表示预训练到可验证的混合求解

**本轮阅读日期：2026-10-02；检索窗口：2026-09-17 至 2026-10-02 检索时点（含与旧快照重叠的 3 天）。**

本轮值得改变的研究判断是：PDE 基座的突破不一定来自更大的主干，也可能来自改变预训练目标、把专家贡献限制在真正互补的空间，或让求解成本与误差要求共同决定何时调用模型。与此同时，表示更紧凑、平均误差更低、误差估计更准确和实际决策更好，是四件必须分别验证的事。

这是 **5 项原文相关章节的新核查**：远程新增登记的 Beyond PINNs、RD-JEPA，以及本次检索补充的 MENO、Cost-Accuracy Trade-offs、力学在线适配研究。后三项只进入研究参考层，没有直接写入主注册表。旧版 **43 条专题记录、42 个工作标识**沿用 2026-09-19 的核查日期，本轮没有重新通读这些论文。所有性能结果仍为作者报告；本轮未运行论文代码或科学实验。

## 2. 线索一：预测潜表征，究竟迁移了什么？

RD-JEPA 把源轨迹用于未来潜特征预测；下游冻结编码器，适配预测器和新解码器。实验留出三种反应律，以 1/5/10 条完整目标轨迹适配；模型用四帧历史直接预测五个时距，且只测一个输出分辨率。它连接了 JEPA 的表征学习与 PDE 少样本迁移，但作者把反应式、扩散式潜分支定义为归纳偏置，未当作精确算子分裂。[Methods 与 Discussion](https://arxiv.org/html/2609.29403v1#Sx3)

对 UPFM 的启发是一个待检验问题：共享模型是否需要优先学会“哪些状态变化可以预测”，再学习精确场读出？如果答案为是，预训练可以把容量投向可迁移动态；如果潜空间丢掉耦合所需的相位、梯度或小尺度，较好的潜损失反而可能掩盖物理失败。这个推断并不证明现有基座应立即更换目标。

**最小区分实验。** 同一源轨迹、容量和算力下比较未来潜预测、未来场预测、状态重构与从零训练；固定目标适配预算、上下文和解码器，再逐一改变目标方程、时间跨度、网格。额外加入潜通路打乱、仅保留最后一帧、逐分支移除的对照。若收益在算力匹配后消失，或均值误差改善而高频和长时结果恶化，应否定“这个潜目标已保留可复用动力学”的强解释。

阅读时还要追问随机性来源：该文的三次结果改变的是支持轨迹选择，预训练 checkpoint 和模型训练随机状态固定；代码与数据承诺随发表公开，本次未找到文中持久版本。不能把这些结果当作多次独立预训练的稳定性验证。[统计口径与公开状态](https://arxiv.org/html/2609.29403v1#Sx3)

## 3. 线索二：用传统数值结构定义“互补”，而不是凭模块名称

Beyond PINNs 在椭圆问题上写出有限元解加能量正交补中的神经修正：$u_h+(I-P_h^a)v_\theta$。有限测量、测试函数和 Gauss–Newton 更新因此进入同一离散解释。意义在于，“如何观察残差”与“用什么模型表示解”都成为可独立改变的部件。[§3–4](https://arxiv.org/html/2609.20641v1#S3)

这提供了一种研究独立专家与共享模型协作的思路：先定义已有模块覆盖的物理方向，再检查新增模块是否补足剩余误差。**这是类比，不是已有专家组合定理。** 文中的投影使用特定能量结构；一般冻结神经专家并不会自动构成有限元子空间，非对称、非线性及动态耦合也可能没有同样的投影。

**最小区分实验。** 从具有可核验能量形式的椭圆问题开始，对照 FE-only、neural-only、直接相加与正交修正。固定测试族、积分精度、神经容量，报告能量误差、系数病态、投影耗时和总成本。若好处只是来自更精确的粗解，或新增投影成本超过同精度求解收益，则应收缩机制解释。

本轮特意保留反面结果：光滑问题中，强残差 GN 也取得相近精度，作者将主要改善关联到残差最小二乘及 GN 处理；混合方法在本来已很准确的 MS 算例上未继续改善。**弱式、混合和更好结果不能被当作同一个原因。**[§5，Tables 1–4](https://arxiv.org/html/2609.20641v1#S5)

## 4. 线索三：固定容量表示，先核查信息损失与测试协议

MENO 用积分矩编码几何和场，在固定模态的全局分支上计算，再向查询点局部分支注入信息。它提醒我们可以把原始采样密度与主干容量分开选择；但“跨几何”的输入/输出载体支持，并不等于一个模型已验证跨 PDE 迁移。[§2–3](https://arxiv.org/html/2609.27739v1#S2)

这里有一个决定证据强度的细节：§4 明确在没有验证集时使用测试准确率选 checkpoint；Table 1 中跨几何 Poisson 和 NASA-CRM 的验证集大小为 0。故这两项结果不能直接作为严格独立测试的胜出证据。其余划分和对比也应分别阅读，而不是据此否定全部表示机制。[§4 Common setting 与 Table 1](https://arxiv.org/html/2609.27739v1#S4)

**最小区分实验。** 在明确的 train/validation/test 划分下，固定 token 数比较积分矩、点/anchor 与局部增强；分别扫描采样密度和保留模态。将编码重构误差、耦合敏感量、下游解误差与端到端显存同时记录，并计入编码预处理和所有查询。若有限模态已经遗漏关键物理变化，继续放大共享主干未必有用；应先修表示。

## 5. 线索四：精度、置信与决策效益需要三套答案

力学适配研究复用取得的有限元完整路径，在固定 POD 基中更新系数映射，并以残差和输入距离等特征建立经验误差接受门。作者分别测了前向误差、接受错误与最终命令选择；改善预测后仍会出现错误接受或拒绝。文中的残差线性解提供估计特征，没有直接修正用于决策的位移。[§3 与 §6](https://arxiv.org/html/2609.33978v1#S3)

这对专家路由的直接启发是：路由分数不该仅仅预测“哪位专家平均更准”，还需回答“这个请求是否落在经过核验的适用范围”。建议把专家输出精度、接受门校准、组合后任务收益分开计分。测试必须包含拒绝使用专家、随机同预算路由、只调用数值方法等选项，否则无法判断复杂门控是否必要。

**最小区分实验。** 固定高保真调用次数与完整轨迹划分，报告接受率、错误接受率、错误拒绝率、失败样本和最终任务损失。若平均误差下降同时错误接受上升，或者只靠更多高保真调用获得改善，就不能认定路由已经更可靠。该研究的引导采集与随机采集还具有不同数量的独立采集集，因此重复训练数也不能被当作独立采集次数。[§5–6](https://arxiv.org/html/2609.33978v1#S5)

## 6. 线索五：让误差容限决定模型与数值方法的分工

Cost-Accuracy Trade-offs 在完全摊销训练和数据成本的多查询极限下，对比修改版 FNO 与多重网格、谱时间推进、有限体积求解。作者所测高精度区间仍未出现统一神经优势；低至中精度的收益可分别来自硬件执行、减少串行时间步、直接预测表面目标量。这是三个任务的经验结果，不是所有未来模型的上限。[§2–4](https://arxiv.org/html/2609.24021v1#S2)

对基座的启发是把研究目标从“全面替代数值方法”改为更具体的问题：对哪些输出、精度和查询频率，共享模型可以减少必须完成的昂贵工作？模型可以生成初猜、低频修正、候选场或目标量预测；传统求解器负责验证或补足。哪种组合有价值，要靠同精度的成本曲线回答。

可用以下**本综述的记账式**组织实验，而不把它当作论文定理：

$$
C_{\mathrm{total}}=C_{\mathrm{data}}+C_{\mathrm{pretrain}}+C_{\mathrm{adapt}}+N_q(C_{\mathrm{encode}}+C_{\mathrm{predict}}+C_{\mathrm{verify}}+p_{\mathrm{fallback}}C_{\mathrm{fallback}}).
$$

每一项都须注明摊销对象；验证成本应包含被拒绝预测和失败回退。不要把一次预训练同时服务多任务的成本重复全额计入每项，也不要在某个模型上省略预处理而在基线上保留。原文的在线计时从已有离散输入开始，不含几何预处理和网格生成，且资源配置不同，这些口径不能隐去。[§3.3](https://arxiv.org/html/2609.24021v1#S3)

# AI 基础、表示、生成与系统：机制驱动的研究综述

> 2026-10-02 增量说明：本文主干继承 2026-09-19，未在本轮全部重读。最新机制、反证与小实验设计见 [10月研究更新](research_update.md)；新旧来源的实际访问日期分别保留。


原主干证据截止：**2026-09-19**；增量核查：**2026-10-02**。本篇是面向整个 AI 的一条独立研究路线，再讨论与 PDE 的交叉，不以 PDE 能否受益作为收录 AI 工作的唯一标准。机器可读证据及知识图谱见 [ai_foundations_evidence.json](ai_foundations_evidence.json)。

核心判断：这条路线的进步由五个相互约束的因素共同塑造——**监督从何而来、表示保留什么、计算如何分配、数据覆盖什么、部署实际受什么资源限制**。Transformer、扩散、状态空间、MoE 不是一列互相取代的版本，而是这些问题的不同解法。2024—2026 年的代表进展进一步表明：同一架构可因数据、目标和硬件实现发生很大变化；单看参数量、训练损失或一个榜单，无法重建创新原因。

## 2. 先明确对象：表示、预测、生成、系统各自在优化什么

四类经常混用的目标必须分开：

| 对象 | 典型问题 | 成功依据 | 容易混淆的结论 |
|---|---|---|---|
| 表示学习 | 表征是否支持多个后续任务？ | 冻结特征、线性探针、部分/完整微调、密集预测分别评估 | 重建更好或全局分类更好，就一定保留全部局部信息 |
| 条件预测 | 给定输入与任务，输出是否正确？ | 任务特定准确度、错误类型、域外与长序列协议 | 语言上合理的结果就是观测忠实的结果 |
| 分布生成 | 能否采样目标条件分布？ | 分布距离、覆盖、似然或校准、约束满足 | 图像逼真就意味着概率正确或科学约束成立 |
| 计算系统 | 给定质量下资源是否更少？ | 训练总成本、吞吐、首包延迟、内存、通信、数值误差 | FLOPs 少或激活参数少，实际延迟就必然更低 |

这是本综述的分析框架，而非某一篇论文提出的统一理论。下面每条路线都保留输入表示、训练信号、评价协议和信息损失的位置。

## 3. 表示学习：从统一交互算子，到识别代理目标的盲点

### 3.1 Transformer 提供可组合的交互方式，不替使用者定义任务

Transformer 的关键是用内容相关的权重直接聚合不同位置的信息。单头形式为

\[
\operatorname{Attn}(Q,K,V)=\operatorname{softmax}(QK^\top/\sqrt{d_k})V.
\]

多头对应不同投影子空间；位置编码补充顺序；编码器—解码器和因果掩码决定信息可以如何流动。它让“token 内的局部表示”和“token 间的关系”可用统一模块组合，但监督仍由任务决定。把图像 patch、语言词元、音频特征或科学观测转成 token，既打开了共享骨架的可能，也引入不同的信息压缩与位置语义。原论文的机器翻译结果不能直接推出所有模态的最优性。[Transformer，§3](https://arxiv.org/html/1706.03762v7)

后续的关键问题因此不是单纯“能否 token 化”，而是：一个 token 覆盖的范围是否抹掉任务所需变化？注意力中的位置是序号、欧氏坐标，还是带单位和边界意义的坐标？同一个交互算子不意味着这些表示契约已经统一。

### 3.2 MAE：把昂贵计算分配给可见内容，把缺失预测作为代理任务

MAE 对图像 patch 做高比例随机遮挡，编码器仅处理可见部分，再由较轻解码器用可见表示与 mask token 重建缺失像素。损失可抽象为

\[
\mathcal L_{\rm mask}=\frac{1}{|M|}\sum_{i\in M}\|\hat x_i-x_i\|_2^2.
\]

这里的收益有两个来源：遮挡迫使模型使用上下文结构，非对称设计则减少主要编码器的训练计算。编码器才是迁移主体，重建解码器可在预训练后丢弃。原文的高遮挡比例建立在自然图像冗余之上，并不是其他数据的通用最佳值。[MAE，§3](https://arxiv.org/html/2111.06377v3)

这一思路把“预测缺失观测”变成通用预训练接口，却没有保证学到的表示对所有任务充分。若缺失信号可以被低频插值解释，重建成绩可能主要反映平滑先验；若不可观测部分具有多解性，确定性 MSE 又可能逼近条件均值。后两点是对迁移边界的分析，需在目标领域实验验证。

### 3.3 DINOv3：全局语义进步与局部结构退化可以同时发生

DINOv3 使用教师—学生式自监督目标，并观察到延长训练时全局分类特征仍在改善，局部密集特征却可能退化。它采用 **Gram anchoring**：比较学生与早期教师的归一化 patch 特征之间的两两相似性矩阵，而非要求每个特征向量逐坐标不变；后续再周期性更新 Gram 教师。这保留局部关系结构，同时允许表示本身移动。[DINOv3，§3.2、§4.1—4.2](https://arxiv.org/html/2508.10104v1)

它对研究方法的重要提醒是：**数据规模、训练步数与任务收益之间可能存在目标冲突**。全局类别、局部边界、精细对应及跨域迁移应独立评估。对于任何需要局部量的模型，不能只以一个全局探针决定表示是否成熟；但 Gram 约束也只是统计关系正则，并没有自动编码守恒、边界条件或严格等变性。

## 4. 多模态：从静态配对，到任务条件和真实时间

### 4.1 CLIP 与 Whisper 说明“监督来源”比“同用 Transformer”更有区分力

CLIP 将图像和文本分别编码，在一批配对中提高真实对应的相似度，以对称交叉熵抑制不匹配对。训练目标学习图文配对关系；文本由此成为开放词汇接口。它不需要为每个新类别重新训练固定分类头，但它对齐的是互联网描述提供的语义，而不是自动获得精确几何或因果变量。[CLIP，§2.1—2.4](https://arxiv.org/html/2103.00020v1)

Whisper 走另一条路线：音频—转录弱监督、标准编码器—解码器、显式任务与时间戳 token。其研究重心是大规模多样语音数据能否支持稳健零样本转移，而不是新发明一个复杂骨架。它并非纯自监督音频模型；语言覆盖、转录质量和片段衔接都会影响结果。作者明确记录重复循环、漏词及与音频不符的输出，因此“语言流畅”与“观测忠实”应分别检查。[Whisper，§2、§6](https://arxiv.org/html/2212.04356v1)

两者的互相启发在于：监督可来自自然配对或弱标签，任务可以经条件接口统一；但语义对应和时序转录是不同的问题。将所有模态映射为一个 embedding 并不能消除标签质量、信息到达顺序或测量尺度的差异。

### 4.2 Qwen3-Omni → Qwen3.5-Omni：时间对齐与服务关键路径成为一等问题

Qwen3-Omni 的 Thinker 处理多模态输入和文本输出，Talker 结合文本及多模态条件输出语音。时间对齐位置编码处理音视频；残差向量量化（RVQ）多码本、MTP 码本预测和因果卷积波形解码实现逐帧流式输出。这里“统一多模态”指输入、条件和训练的组合，不能误写成它同样生成图像和视频。[Qwen3-Omni，§2](https://arxiv.org/html/2509.17765v1)

Qwen3.5-Omni 明确承接前者，新增显式时间戳以缓解长视频绝对位置索引稀疏，并通过 ARIA 约束文本和语音的自适应交错：任意生成前缀的累计语音/文本 token 比，不超过该样本的总体比。其目的在于减少不同语言、不同 token 率造成的错位。音频编码率进一步下降，Hybrid MoE/Gated Delta Net、分块 prefill 和波形解码共同服务长序列效率。预训练也分为编码器对齐、全参数一般阶段与长上下文阶段。[Qwen3.5-Omni，§2—3](https://arxiv.org/html/2604.15804v2)

这条演化不是只靠“添加一种模态”，而是逐步处理三个瓶颈：**语义是否对应、物理时间是否对应、服务能否在信息未全部到达时开始输出**。其首包延迟依赖整条关键路径。Qwen3.5 报告也明确说明不同型号使用不同资源配置，不应直接用延迟数字做严格横向排名。本次没有复现其数据规模或能力声明；2026 年报告提供了新设计证据，没有给出全领域稳定最优解。

## 5. 生成建模：学习什么路径，使用什么骨架，在哪个空间生成

### 5.1 DDPM 将难的分布生成拆成多尺度去噪

DDPM 固定一个逐步加噪过程，可直接在任意噪声时刻构造训练样本：

\[
x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,
\qquad
\mathcal L_{\epsilon}=\mathbb E\|\epsilon-\epsilon_\theta(x_t,t)\|_2^2.
\]

模型学习逆过程的噪声参数化；简化 MSE 与原始变分目标存在重加权关系，不能把较佳视觉样本质量直接解释成最优似然。训练可随机抽取时刻，生成却需要多次逆过程计算，因而训练吞吐与采样成本应单独计算。[DDPM，§2—3、Algorithms 1–2](https://arxiv.org/html/2006.11239v2)

### 5.2 Flow Matching 把概率输运转为条件速度回归

Flow Matching 学习向量场，使简单分布沿一条概率路径到达数据分布。边缘速度一般不可直接计算，但可构造易采样的条件路径，最小化

\[
\mathcal L_{\rm CFM}
=\mathbb E_{t,z,x_t\sim p_t(\cdot\mid z)}
\|v_\theta(x_t,t)-u_t(x_t\mid z)\|_2^2.
\]

在原文条件下，这与边缘流匹配目标具有相同参数梯度。创新是把难的边缘监督转换为容易构造的条件监督，训练不必反复数值模拟整个流；生成时仍需求解 \(\dot x_t=v_\theta(x_t,t)\)。所以 simulation-free 描述训练，不表示采样无需数值方法。[Flow Matching，§3、Theorems 1–2](https://arxiv.org/html/2210.02747v2)

扩散与流匹配可共享网络、条件接口及部分路径设计语言，但不是把一个名称替换成另一个就得到同等性能。路径、预测参数化、损失权重、积分器、步数和条件策略共同决定结果。尤其要区分生成变量 \(t\) 与被建模系统的真实时间：生成过程即使满足连续性方程，也没有因此成为所研究物理系统的演化方程。

### 5.3 DiT 把架构选择与生成目标拆开

DiT 在已有 VAE 的压缩潜空间上划分 patch，用 Transformer 构成扩散模型。其条件设计比较了 token 拼接、cross-attention 和自适应归一化；adaLN-Zero 将时间/类别条件用于仿射及残差调制，初始残差近似恒等映射。减小 patch 会增加 token 和计算，即使参数量近乎不变。[DiT，§3](https://arxiv.org/html/2212.09748v2)

这说明三个设计轴应分别记录：**分布目标**（如噪声或速度预测）、**函数骨架**（如 Transformer）、**生成空间**（像素或潜变量）。潜空间减少高分辨率成本，同时把信息恢复上限交给编码器—解码器。对自然图像可接受的感知损失，在计量或科学任务中可能抹掉关键小尺度；这属于必须额外测量的迁移风险，不是 DiT 原论文已经回答的问题。

## 6. 长序列与容量：状态压缩、结构化对偶、稀疏计算是不同轴

### 6.1 Mamba 的问题是选择性记忆，不是给循环网络改名

Mamba 令部分状态空间参数依赖输入，用选择机制决定保留与过滤什么。可用离散形式理解：

\[
h_k=\bar A_k h_{k-1}+\bar B_k x_k,\qquad y_k=C_k h_k.
\]

有限状态带来随序列长度线性扩展的计算形态，也限制可保留的上下文信息。输入依赖破坏了时间不变系统的简单卷积实现，因此选择性 scan 必须与融合、并行扫描、重计算以及 GPU 存储层级共同设计。[Mamba，§3.1—3.3](https://arxiv.org/html/2312.00752v2)

与注意力相比，这是一种不同的资源分配：注意力保留可寻址上下文，状态模型持续压缩过去。哪个更有效，取决于任务需要全部历史、少量充分统计量，还是偶发的精确远程检索；复杂度本身不能回答。处理多维空间时，扫描顺序也变成额外假设。

### 6.2 Mamba-2/SSD 解释一部分架构为何可以共享算法

SSD 建立的精确对偶有明确范围：状态转移为标量乘单位阵的特定 SSM，与具有 1-半可分结构掩码的注意力相交。同一运算既可呈现为递推形式，也可呈现为两两交互形式，进而支持不同分块计算。它不是任意 softmax Transformer 与任意 SSM 的全等定理。[Mamba-2/SSD，§5.1—5.3](https://arxiv.org/html/2405.21060v1)

其启发是用矩阵结构理解架构，然后选择适合硬件的计算形式；这样能区分表达类、算法复杂度与实现吞吐三个层次。只凭标题判定“注意力已经被证明等于 SSM”，会删除真正重要的结构条件。

### 6.3 DeepSeek-V3：稀疏专家、KV 压缩和低精度各自处理一种成本

DeepSeek-V3 同时采用 MLA 的 K/V 低秩联合压缩、共享与路由专家、MTP 训练目标及 FP8 混合精度。路由偏置用于负载均衡，但原文仍含较小的序列级均衡辅助损失，不能将 auxiliary-loss-free 写成“完全没有辅助损失”。MTP 扩大训练预测范围，也可在推理时用于推测解码；这两个用途应分开评估。[DeepSeek-V3，§2、§3.3](https://arxiv.org/html/2412.19437v2)

MoE 扩大的是“总参数容量相对于单 token 激活计算”的比例，不保证总内存同幅下降；MLA 针对缓存，低精度针对运算/存储，路由则产生通信和负载问题。把这些贡献合并成一个参数量数字，会无法解释实际成本。一个领域专家是否对应可解释的知识或物理机制，也是需要诊断的假设，不能由专家名称得出。

## 7. 缩放与数据：从固定预算分配，到承认数据改变规律

Chinchilla 研究的是给定训练 FLOPs，模型参数和训练 token 怎样联合分配。其多种拟合支持在所研究设置中共同增加两者，反对无视数据不足而只扩大参数。一个通用表达为

\[
L(N,D)\approx E+aN^{-p}+bD^{-q},\qquad C\approx kND.
\]

这里 \(a,b,p,q,E\) 都是待估计量；为了避免不同论文记号混淆，本篇另用 \(p,q\)。原论文指出大模型验证点有限、可能出现曲率、分析主要处于不足一个 epoch 的范围。由此不能把某个 token/参数比例推广为所有数据、推理预算或重复训练的固定法则。[Chinchilla，§3、§5](https://arxiv.org/html/2203.15556v1)

DCLM 把数据策略变成可比较的实验变量：固定不同尺度的训练配方，比较过滤和混合，统一评估下游任务。候选池规模、清洗后数据量、实际训练 token 必须分开；其 240T 是候选池，提供去污染工具也不等于整个池已经完成去污染。小尺度数据策略与大尺度结果的相关性给出低成本筛选依据，但只是其测试范围内的经验结果。[DCLM，§3](https://arxiv.org/html/2406.11794v4)

QualityPajama 进一步系统改变数据去重、启发式筛选和改写，在 23 套数据上研究 2000 余个模型。发现变化不只落在“等效 token 数”上：拟合系数、指数以及不同策略的排序均可能改变，而且受验证域和预算影响。其训练范围为 100M—8B 参数、100M—200B token；超出范围的巨大计算收益必须标作拟合外推，本篇不将其当作实测加速。[QualityPajama，§3—6](https://proceedings.iclr.cc/paper_files/paper/2026/file/6544c0b53cc1ea51d0c7086b536830a8-Paper-Conference.pdf)

DCLM 的“某些排序在测试尺度上相关”与 QualityPajama 的“排序可以改变”不矛盾：前者是有限实验中的有效筛选线索，后者否定的是无条件外推。可迁移的方法是**受控干预、多尺度复测、保留验证域差异**，而非寻找一个永远最优的清洗分数。

理论方面，double descent 提醒我们，越过插值阈值后增加容量可能再次降低测试风险；模型选择及归纳偏置决定在众多零训练误差解中取哪个。它修正“参数更多必然过拟合”的简单直觉，但没有证明任意过参数模型都可靠，更没有自动覆盖分布外或因果泛化。[Double descent，§1、§4](https://arxiv.org/html/1812.11118v2)

因此经验 scaling 与学习理论应互相约束：前者提供资源规划的局部预测，后者提醒辨别分布、函数类和优化选择。把经验曲线称为自然定律，或把有限类理论称为大模型全部能力的解释，都超出本次证据。

## 8. 系统效率：少一次显存读写有时比少一个理论运算更重要

FlashAttention-3 在 Hopper 上利用异步搬运、producer/consumer warp 分工和矩阵乘—softmax 的调度重叠。局部 softmax 避免将完整中间注意力矩阵写入显存；FP8 又带来布局与数值误差处理。这是数学目标、计算图和硬件实现共同设计的实例。它没有把稠密注意力所有 FLOPs 变为线性；论文还明确留下推理优化与大规模低精度训练影响等问题。[FlashAttention-3，§2—3、§5](https://arxiv.org/html/2407.08608v2)

结合 Mamba 的 scan 和 DeepSeek-V3 的混合精度，可以得到一套比“模型复杂度”更有解释力的检查顺序：先判断瓶颈是矩阵乘、内存带宽、通信、串行依赖还是解码步数，再决定优化位置；最后在相同质量约束下测量端到端结果。低精度更要记录敏感算子保留精度、误差分布和累积效应。论文中的硬件峰值与单内核吞吐，不能直接替代完整训练或服务成本。

## 9. 发展脉络、分歧与前沿稳定性

以下是本综述归纳的“问题推动”关系；除 Qwen 报告明确比较自身版本、以及原文陈述的机制继承外，不把先后年代自动标成历史引用因果。

| 早期有效解法 | 随规模/任务暴露的问题 | 所读代表工作中的回应 | 仍待解决的分歧 |
|---|---|---|---|
| token 注意力统一交互 | token 多、上下文缓存大 | Mamba/SSD、MLA、FlashAttention-3 | 保留可寻址记忆还是压缩为状态；哪种任务会损失关键记忆 |
| 单一代理任务预训练 | 全局与局部信息不一致 | MAE 的非对称重建；DINOv3 的关系约束 | 哪种预训练信号与目标任务充分信息真正一致 |
| 配对数据对齐模态 | 长音视频时钟、异速输出、首包延迟 | Whisper 任务/时间戳；Omni 系统的时间对齐与 ARIA | 降低 token 率损失多少细节；语义质量与时间忠实如何兼顾 |
| 多步生成形成高质量分布 | 高维空间及多步采样成本 | 条件流匹配、潜空间 DiT | 压缩误差、路径误差、积分误差应怎样分配预算 |
| 扩大模型提高容量 | 数据不足、负载与通信限制 | Chinchilla、MoE、混合精度 | 总参数、有效数据和生命周期成本谁是瓶颈 |
| 清洗后继续套用同一 scaling | 数据改变任务分布和拟合规律 | DCLM、QualityPajama | 小尺度结果可迁移到多大；质量如何保留长尾 |

相对稳定的是机制层判断：代理目标需要下游核验；有限记忆存在信息选择；条件计算仍受路由开销约束；训练预算与数据必须共同规划；生成采样需要成本核算。尚不稳定的是“最优”配置：遮挡率、压缩率、数据配比、固定 token/参数比例、混合架构占比、低精度粒度和推理步数。2025—2026 年大系统技术报告对设计方向有价值，但其广泛领先、绝对延迟与规模可复现性需要独立证据；本篇不将这些声明提升为领域共识。

## 10. 与 PDE 研究的接口：迁移机制，同时重新定义成功条件

下表是本综述提出的跨领域分析，不声称所引 AI 原论文已经验证 PDE 收益。

| 可迁移机制 | PDE 中需要重新定义的接口/实验 | 明确不适用的直接类比 |
|---|---|---|
| MAE/DINO 式局部—全局学习 | 遮挡应覆盖传感缺测、空间块和时间段；分别测试局部重建、通量与长程预测 | 图像裁剪/颜色不变性不等于物理等变性；像素 MSE 不能单独代表守恒 |
| CLIP/Whisper 的条件与任务 token | 方程、单位、参数、初边值、几何应具备可核验解析与绑定；检查条件替换是否改变正确变量 | 语言描述相似不等于方程算子相同；流畅输出不等于数值可信 |
| Omni 时间对齐 | 对异步传感器用真实时间戳、采样率和缺测状态；改变采样间隔检验一致性 | token 索引不能直接充当物理时间；语音播放连贯不证明动力学稳定 |
| 扩散/流匹配 | 明确学习后验、多解集合还是未来状态分布；评价覆盖、校准、残差与边界条件 | 生成时间不等于物理时间；概率流连续性不自动满足目标 PDE |
| DiT 潜空间、MLA、SSM | 先测压缩的高频、边界、极值与不变量误差，再测预测；记录空间扫描顺序 | 好看的重建不保证科学量可恢复；SSM 隐状态不自动具有物理可解释性 |
| MoE 条件计算 | 路由按局部状态或方程条件形成的分工需要诊断，评估罕见状态与跨专家连续性 | 专家编号不等于物理机制；低激活 FLOPs 不等于低通信或无负迁移 |
| DCLM/QualityPajama 数据干预 | 控制独立轨迹、参数覆盖、求解器精度和测试族；同轨迹切片不能冒充独立样本 | token 数不等于独立物理信息量；文本清洗最优策略不直接等于数值数据最优策略 |
| FlashAttention/FP8 | 在固定误差容限下测端到端性能，单独评估长滚动与敏感算子的舍入误差 | 语言 loss 接近不能替代 PDE 稳定性、误差界或守恒验证 |

可据此提出三个具体且可证伪的研究问题，而不是直接拼装新模型：

1. **表示充分性**：固定下游预测器与预算，比较预训练目标改变后，局部密集量、全局状态和边界量是否同向改善？若只有全局指标提高，机制解释应保留目标冲突。
2. **有效数据**：固定求解器可信度与参数域，改变独立轨迹数、每轨迹采样密度和数据质量，分别拟合缩放曲线。若密采样收益饱和，应承认 token 规模不能代表新增信息。
3. **压缩与数值成本**：在统一误差阈值下比较注意力、状态模型、潜空间和低精度，分解重建、预测、积分及舍入误差，再讨论速度收益。若节省来自放宽精度，不能归因于架构优势。

这些是假说与辨别实验设计，没有启动训练或产生新的科学结论。
